# requirements-render.txt - Phase 4 (render) only, EXACTLY pinned.
#
# Why a separate file: the pod runs main.py + the templates, nothing else. It
# does not need langgraph/aiohttp/tenacity (Phases 1-3), and it must NOT drift
# from the laptop - an unpinned `manim>=0.18.0` installs whatever is newest and
# silently changes how frames rasterize, which defeats the whole point of
# rendering in the cloud.
#
# Every pin below is the version actually running in the local .venv,
# read off `pip list` on 2026-08-24. Laptop python is 3.10.11.
#
#   pip install -r requirements-render.txt
